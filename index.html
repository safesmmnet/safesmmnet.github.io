Open-source examples, libraries and guides for connecting your app, bot or reseller website to the SafeSMM SMM panel through the standard API v2.

What is the SafeSMM API?

SafeSMM uses the common SMM panel API v2 format. You send a POST request with your API key and an action, and you get JSON back. If you already work with another panel that uses this format, your code usually needs only a new URL and key.

Endpoint: https://safesmm.net/api/v2
Method: POST   Response: JSON
Official reference: SafeSMM API documentation
API key: create a free account, then open the Account page.

Quick start

cURL

curl -X POST https://safesmm.net/api/v2 \
  -d "key=YOUR_API_KEY" \
  -d "action=balance"

Python (pip install safesmm)

from safesmm import SafeSMM

api = SafeSMM("YOUR_API_KEY")
print(api.balance())
order = api.add_order(service=1, link="https://example.com/post", quantity=100)
print(api.status(order["order"]))

A wrong key returns {"error": "Invalid API key."}. Always check for an error field before reading the result.

Best practices for resellers

1. Call services once and cache it. Refresh a few times a day, not on every request.

2. Check status in batches (up to 100 IDs per call) every few minutes instead of every second.

3. Validate quantity against the service min and max before sending an order.

4. Keep the API key on your server. Never put it in front-end JavaScript or a public repository.

5. Use drip-feed for large orders so delivery looks gradual. Each run must be at least the service minimum.

6. Store the order ID returned by add so you can request a refill or cancel later.

FAQ

Is the API free to use?

Yes. There is no API fee. You only pay for the orders you place, at the rates shown on the services page.

Can I connect my own reseller panel?

Yes. Most panel scripts support API v2 providers. Add the endpoint and your key as a provider, then import services. More details on the reseller panel page.
